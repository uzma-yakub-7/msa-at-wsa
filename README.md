# WSA MSA Website
Official website for the Muslim Student Association at Westchester Square Academy (WSA MSA), featuring events, leadership, resources, membership, and community information.


## Project

The website provides information about:

- About the MSA
- Upcoming Events
- Past Events
- Leadership
- Resources
- Membership
- Contact Information

## Technology

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- PostgreSQL
- Neon
- Render

## Hosting

The project is hosted through Render.

GitHub is used as the source-code repository.

GitHub Pages is not used.
